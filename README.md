## 🏗 Ключові будівельні напрямки та нормативи

### 1. Капітальне мурування та зведення стін
- Зведення несучих зовнішніх та внутрішніх стін із газобетонних, керамічних блоків та цегли.
- Обов'язкове дотримання нормативів армування та влаштування монолітних армопоясів.
- Пошук перевірених фахівців: [Мурування стін на Zbuduy](https://zbuduy.com/muruvannia).

### 2. Електромонтажні роботи та безпека
- Проєктування трипровідної однофазної або п'ятипровідної трифазної електромережі.
- Розподіл силових та освітлювальних ліній із захистом ПЗВ (10–30 мА) та реле перенапруги.
- Каталог фахівців: [Послуги електрика](https://zbuduy.com/elektryka).

### 3. Сантехніка, водопостачання та опалення
- Колекторна розводка трубопроводів із труб PE-Xa з кисневим бар'єром.
- Встановлення автономних систем підігріву води, радіаторного опалення та теплої підлоги.
- Каталог фахівців: [Сантехнічні послуги](https://zbuduy.com/santekhnika).

### 4. Оздоблення, плитка та керамограніт
- Лазерний контроль горизонтальності стяжки та вертикальності штукатурки (допуски ≤ 1.5 мм).
- Професійне різання та укладання керамограніту: [Плиточні роботи на Zbuduy](https://zbuduy.com/plytka).

### 5. Спецтехніка та земляні роботи
- Механізоване риття котлованів, траншей під фундамент та планування ділянки екскаваторами: [Оренда спецтехніки в Україні](https://zbuduy.com/spetstekhnika).
